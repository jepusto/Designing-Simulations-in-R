
This is the repository for the in-progress book _Designing Monte Carlo Simulations in R_, which can be previewed at (https://jepusto.github.io/Designing-Simulations-in-R/). The book is written using [Quarto](https://quarto.org/) and R.

This book is now in quarto.  To render, try the following on the R console:
```
quarto::quarto_render()
```
